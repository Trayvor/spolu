## A. Create from the admin global views, and "only where I take part"

Already built, not part of A: the admins' global knowledge list (Phase 17) and the global task board
(Phase 20), both with the client filter whose default is "My clients" and an "All clients" choice, and
the board's assignee filter (me, anyone, unassigned, a person).

What A adds:
- On the global knowledge list and the global task board, an admin can create a knowledge item or a
  task. They must pick its client first; there are no items without a client.
- On the global task board, a filter **"only where I take part"**: tasks I created or am an assignee of.
- Dropped by the owner (2026-10-16): "internal" items that belong to no client.

## B. Technical support module (tickets), on 2 levels

Client level and an admin overview with filters. A support board.

- Tickets arrive through an API with these fields, all optional:
  - requester name, email, phone number;
  - question area, subject (title), grant programme name;
  - body;
  - links to files;
  - due date;
  - URL link;
  - link to the instance (the client's eGrant instance).
- Each ticket has its own chat.
- An incoming ticket is assigned to a client automatically by the instance link.
- Admins and managers can **follow** a ticket and get notifications about its changes.
- A ticket can be turned into tasks with AI, like a chat message. The task links to the ticket and
  the ticket to the task.
- The requester:
  - **Already in the client's group:** gets an email that the ticket was created. Clients have access
    to the ticket board.
  - **Not yet a client:** is added to the client's group in a new role **`ziadatel`**. This role sees
    only the ticket board and the communication on their tickets, not even the task board, and only
    their own tickets. One ziadatel can belong to several clients.
- Managers and admins can create a ticket by hand and set who initiated it (email and name, as from
  the API). The initiator gets an email, and the ticket shows in their tickets (a new ziadatel
  account is created if needed).

## C. Extended notification settings in the profile

- Notification groups, each with a channel choice: **email, push, both, or none**.
- Groups: **chat, task board, ticket board, knowledge base**.
- A ziadatel sees only the ticket board group.
- Defaults:
  - ticket board: push and email on;
  - every other group: push only.
