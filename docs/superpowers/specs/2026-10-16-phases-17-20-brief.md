# Next phases: the owner's brief and decisions (2026-10-16)

The owner wrote in Ukrainian. This is a faithful English rendering. Build after Phases 9 and 6, and run things in parallel as much as possible.

## A. Knowledge base

- A module where people create "knowledge" items. These are cards of different types.
- **Visibility:**
  - A client always creates public items.
  - An admin chooses public (admins and the client see it) or non-public (admins only) when creating an item.
- **Type 1: note.** A text field like the chat composer (same formatting), plus files.
  - In the list: title, number of attached files, and the start of the body on one line ending with "...".
  - Clicking the card opens the full detail.
  - The owner asked us to decide between a separate window and a popup, as long as it fits on phones.
- **Type 2: file.** One file, with a title and a description.
  - In the list: a file icon.
  - Clicking the file name downloads or opens the file in the browser.
  - Clicking elsewhere on the card, or on the description (shown like the note body), opens the detail with the description.
- **Type 3: link.** Like type 2, but a URL instead of a file. The URL opens when the card's text is clicked.
- **Type 4: reminder.** Like type 1 without files, plus reminder times.
  - One or more date+time values.
  - A button to export to a calendar.
- **Reminders on the task board.** Add the same reminder module to the task board. The board already has deadline and urgent reminders (Phase 6), so think about how the two fit together.

## B. Admin side

1. **Client manager.**
   - An admin can "become manager of a client" and stop being one. The button is in the view of all clients.
   - Becoming manager turns on all notifications from that client for this admin, unless the admin changes the setting.
   - Only managers can be @-mentioned in that client's chat or chosen as task assignees. Admins who are not managers do not appear in mention and assignee pickers.
   - A non-manager admin can still read and write the chat and everything else.
   - For all admins on all clients the notification default is mentions only. Being a manager makes it All for that client.
2. **Admin dashboard cards.**
   - **Assigned tasks:** a wide card. On the left, the count of tasks assigned to me and how many are urgent. On the right, a list in chronological order: urgent first, then the nearest deadline, then later ones, then tasks with no deadline.
   - **Upcoming reminders:** chronological, with the count on the left.
   - **Unread messages where I was mentioned:** the count on the left and the list on the right. Clicking a message opens the chat at that message.
   - Clicking an item on every card goes to the item.
3. **Client list.**
   - Move the list to the left and make it compact. The dashboard goes on the right.
   - Clients I manage and other clients are visually separated.
   - Order: clients with unread messages first, then clients that have tasks assigned to me.
   - Each client shows its unread count and its count of tasks assigned to me.
   - In the group's own tab bar, the Úlohy tab shows the same: a black dot with the unread count, and a **yellow** dot with the number of tasks assigned to me.

## Owner answers (2026-10-16)

- **Where the knowledge base lives:**
  - Each group has a knowledge tab.
  - Admins also get a global list of all knowledge from all clients in the main menu, above the groups.
  - The global list filters by client. By default it shows only the clients this admin manages, and the admin can remove some or add others, from managed clients and from other clients, which are visually separated.
  - It also filters by type and searches by title, description, file name or URL.
- **Global task board:** the same thing for tasks. Admins get a global task board across all clients, with the same client filtering.
- **Reminder recipients:** the author, plus people the author adds. People can also subscribe to a reminder themselves.
- **Edit and delete:** the author and admins.
- **@all:** reaches the group's clients and that client's managers. Non-manager admins are not reached by @all and are not listed for mentions or assignees.

## Controller rulings (the owner may override)

- **Phase numbers:** the roadmap already has phases 0–16. New phases are numbered from 17.
- **Knowledge detail:**
  - Desktop: a centred dialog, 720 px.
  - Phones: a full-screen sheet, reusing the task panel sheet primitives.
  - Each item is addressable by URL (`?k=<id>`), so links and notifications open it.
- **Calendar export:** a standard `.ics` file with one VEVENT per reminder time. It works with Apple, Google and Outlook calendars.
- **Reminder delivery:** reminders go through the Phase 6 notification pipeline as a new event kind. They are delivered in modes All and "Mentions and replies", like task events, but not in Off.
- **Non-public items:** visible to all admins, not only managers.
- **Managers:** many-to-many. A group can have several managers, and an admin can manage several groups.
